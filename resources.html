Serial logs and the replay program

For the core and the standard features you need only a serial monitor, for example the Serial Monitor in the Arduino IDE. Save its output as a log file for your evidence, and name the test it belongs to.

The PC program that sends replay data for the challenges, the replay format and example data sets will be added here before you start the challenges.

What changed

18 November 2026

Standard features and feature wording

Each standard feature is now worth 1 mark, with at most 3 features from each of the four categories, prerequisites included. The picker stops you choosing a fourth in a category.

R02 (watchdog) has been removed. P06 no longer needs P01, and challenges X2 and X5 no longer need M04 and M02. Holding D0 for 2 seconds or longer must return to Home (C10). Many feature descriptions were made more exact, so read the feature tables again before you write your requirements.

17 November 2026, evening

Testing, submissions and marks

The core and the standard features are now tested on the real board. The serial test protocol is gone, and so is core feature C11. C12 now asks for readable live serial output, described on the Serial output page. Serial replay is needed only for the challenges, and its format will be published later.

The first submission asks for requirements and an early binary, with no test plan. The workbook shows the Tests, Results and Access tabs once you set Submission to Final.

The final 30 marks are now split 8 for the core, up to 12 for standard features and up to 10 for two challenges (provisional). Each feature is marked half on how well it works and half on your requirements, tests and evidence. Your monitor needs a Home screen, and the final submission includes a Feature Access Guide. P03 is now part of C13. The challenges have their own page.

17 November 2026

Workbook, picker and roadmap

The workbook checks your project details and features before you download the file for Blackboard. The backup button is now called Download backup to keep, because backups are not submitted. The claim, the Results tab and the changes note appear when you set Submission to Final in Project details.

On a shared lab PC, choose Finish on this PC in the workbook before you leave. It downloads a backup and then removes your workbook, feature choices and roadmap ticks from that browser.

The picker shows the standard feature share as to be announced and no longer shows a plan total. You can now read the worked EX1 example on this page.

16 November 2026

Project workbook

Write and review your plan in the workbook. Download a dated copy to keep your work or continue on another computer.

16 November 2026

Project guide and feature planning

Use the roadmap and picker for the first submission. The worked EX1 files now agree on the humidity boundary. With a maximum of 70%, a clear setting of 69% is accepted and 70% is rejected.

Deadlines, standard feature weights and the challenge replay format will be announced here.
