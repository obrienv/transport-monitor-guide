Sending test messages by hand until then

  1. Open a serial monitor on the board's USB port, for example the Serial Monitor in the Arduino IDE.
  2. Set the line ending to Newline, because every protocol message ends with a newline.
  3. Copy one request line from the protocol page (each example has a Copy button), paste it and send it.
  4. Read the one reply line and compare it with the expected reply. Save the monitor output as your log.

What changed

17 November 2026

Workbook, picker and roadmap

The workbook checks your project details and features before you download the file for Blackboard. The backup button is now called Download backup to keep, because backups are not submitted. The claim, the Results tab and the changes note appear when you set Submission to Final in Project details.

On a shared lab PC, choose Finish on this PC in the workbook before you leave. It downloads a backup and then removes your workbook, feature choices and roadmap ticks from that browser.

The picker shows the standard feature share as to be announced and no longer shows a plan total. You can now read the worked EX1 example on this page.

16 November 2026

Project workbook

Write and review your plan in the workbook. Download a dated copy to keep your work or continue on another computer.

16 November 2026

Project guide and feature planning

Use the roadmap and picker for the first submission. The worked EX1 files now agree on the humidity boundary. With a maximum of 70%, a clear setting of 69% is accepted and 70% is rejected.

Deadlines, standard feature weights, the X6 evidence arrangements and challenge serial commands will be announced here.
