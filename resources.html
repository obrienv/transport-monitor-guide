Serial logs and the replay program

For the core and the standard features you need only a serial monitor, for example the Serial Monitor in the Arduino IDE. In the workbook, state which serial output to observe during the test, what you expect to see and what you actually observed.

The PC program that sends replay data for the challenges, the replay format and example data sets will be added here before you start the challenges.

Submission checklist

Submit source code, one full merged firmware image and the workbook Markdown for each part. Record the test steps and results in the workbook. Use the submission instructions to export and check your merged image.
